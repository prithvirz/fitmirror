# Contributing

FitMirror is one `index.html`, no build step.

1. Fork and clone, then open `index.html` in a browser (or `python3 -m http.server 8080`).
2. Make a small change and test one try-on end to end.
3. Run `node tests/smoke.mjs` (checks the AI Space is up and the endpoint matches).
4. Open a pull request that says what changed and why.

Good first tasks are in the issues labelled `good first issue`.
